# Lucas Oskwarek Tennis

Simple, mobile-first site for 1-on-1 private tennis lessons in Middlebury, Southbury and Greater Waterbury, CT.
Static HTML generated by `build.py` from `site.json`, published by GitHub Pages from the `main` branch root.

Live: https://noahoskwarek-bot.github.io/lucas-tennis/

## Edit the text

All words on the site live in `site.json` (keys starting with `_` are notes, not shown on the site):

- `header_top` / `header_bottom`, `tagline`, `kicker`, `intro`: the top of the page
- `why`: the "Why train with Lucas?" list (wording from Lucas's flyer)
- `experience`: the experience cards (from Lucas's resume)
- `areas` (shown) and `area_cities` (for search engines): lesson area
- `title`, `description`: search result title and description, also used for link previews
- `book_title`, `book_text`: the booking section

The lesson request form is the only contact method on the site; no phone number or email address is published.

## Rebuild

```
python3 build.py                 # writes index.html, thanks/, 404.html, sitemap.xml, robots.txt, site.webmanifest
python3 build.py --check         # exits 1 if anything is out of date; run before committing
BUILD_DATE=2026-10-22 python3 build.py   # optional: pin the sitemap date so rebuilds don't create date-only changes
git add -A && git commit -m "Update site" && git push
```

Styles are in `src/style.css` (inlined into each page by the build). No JavaScript, no web fonts, no photos.

## Change the price

1. In `site.json`, set `"price"` (whole dollars, e.g. `40`) and update the `$35` inside `"description"`.
2. Run `python3 tools/make_brand.py` so the share image (`images/og-image.png`) shows the new price.
3. Run `python3 build.py && python3 build.py --check`, then commit and push.

## Lesson request form (FormSubmit)

- The endpoint is `form_endpoint` in `site.json`, currently `https://formsubmit.co/lnotennis+lucas-lessons@mail.grokbot.com`.
- **Activation:** FormSubmit sends a one-time activation email to that address on the first real submission. Nothing is delivered until someone clicks **Activate** in that email.
- After activation, FormSubmit offers a random-string alias. Swap it in by setting `form_endpoint` to `https://formsubmit.co/<alias>` and rebuilding, which keeps the address out of the page source.
- Fields sent (shown in the email table): `name`, `phone_or_email`, `skill_level`, `town`, `preferred_times`, `message`.
  Hidden: `_subject` (`form_subject`), `_template=table`, `_captcha` (`form_captcha`), `_next` (the `/thanks/` page) and the `_honey` spam trap.
- Skill level and town choices are `skill_levels` and `form_towns` in `site.json`.
- Set `form_endpoint` to `null` to hide the form.

## Logo, favicon and share image

`python3 tools/make_brand.py` draws the tennis-ball mark (`brand/mark.svg`), the favicons, app icons and the 1200x630 share image with headless Chrome and Pillow. Re-run it after changing the colours, price or header text.

Colours: dark green `#1b5e20`, deep green `#0f3d17`, ball yellow-green `#c8f03c` (used only on green, never as text on white, for AA contrast), white.

## Custom domain later

Set `base_url` in `site.json` to the new address (e.g. `https://www.example.com`), add a `CNAME` file with the domain, rebuild and push, then set the domain in the repo's Pages settings.
